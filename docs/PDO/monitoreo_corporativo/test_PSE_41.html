Suite independiente de pruebas unitarias y de integración para la Historia de Usuario PSE-41: Generación y Exportación de Reportes de Transacciones y Ganancias (Épica PSE-23).

Valida:

  • Filtros combinables: rango de fechas, tipo de operación, moneda, cajero y cliente.
  • Consolidación en PYG de volúmenes, comisiones, IVA y ganancia neta (comisión − IVA), incluida la conversión de comisiones que no se guardaron en Guaraníes.
  • Exclusión de operaciones no confirmadas (FAILED, PENDING, ANULADA).
  • Generación y estructura del CSV (Excel/CSV), del archivo PDF (ReportLab) y de la vista de impresión del navegador (window.print()).
  • Control de acceso: Administrador y Analista sí; Cliente no.

 94    def _crear(self, modelo, fecha, cliente=None, user=None, turno=None, desde='PYG', hacia='USD', monto='0',
 95               convertido='0', tasa='1', comision='0', iva='0', total='0', estado='SUCCESS', ventanilla=False):
 96        """Crea una transacción y fija su fecha (``timestamp`` es auto_now_add)."""
 97        tx = modelo.objects.create(
 98            user=user, cliente=cliente, turno=turno, from_currency=desde, to_currency=hacia,
 99            amount=Decimal(monto), converted_amount=Decimal(convertido), applied_rate=Decimal(tasa),
100            standard_rate=Decimal(tasa), commission_amount=Decimal(comision), tax_amount=Decimal(iva),
101            total_pyg=Decimal(total), status=estado,
102            payment_method_type=reportes.PAGO_VENTANILLA if ventanilla else 'TRANSFERENCIA',
103        )
104        modelo.objects.filter(pk=tx.pk).update(timestamp=fecha)
105        tx.refresh_from_db()
106        return tx
